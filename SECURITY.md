# Security / Güvenlik

**English:** Use only on devices you own or are authorized to administer. Terminal access has the privileges of the local agent account. HTTPS/WSS and local capability opt-ins are required. Never publish keys, bootstrap passwords, recovery codes or customer screenshots. Report vulnerabilities privately through [GitHub security advisories](https://github.com/tahayildirm/remvora-agent/security/advisories/new). Do not disclose vulnerabilities or personal data in public issues. Security support/SLA and independent audit are not promised. See docs/STATUS.md and docs/PUBLIC_RELEASE.md.

**Türkçe:** Yalnız sahip olduğunuz veya yönetmeye yetkili olduğunuz cihazlarda kullanın. Terminal, agent hesabının işletim sistemi yetkileriyle çalışır. HTTPS/WSS ve cihaz tarafında özellik izinleri gerekir. Anahtar, bootstrap parolası, kurtarma kodu veya müşteri ekranı yayımlamayın. Açıkları [GitHub özel güvenlik bildirimi](https://github.com/tahayildirm/remvora-agent/security/advisories/new) üzerinden iletin. Genel issue’da açık ayrıntısı/kişisel veri paylaşmayın. Güvenlik SLA’sı veya bağımsız denetim vaadi yoktur. docs/STATUS.md ve docs/PUBLIC_RELEASE.md dosyalarına bakın.
