# Contributing / Katkıda bulunma

**English:** Keep each component in its own repository. Discuss substantial changes in an issue; submit focused pull requests with purpose, behavior, validation and migration/rollback notes. Update English and Turkish documentation/UI together. Follow existing formatting, run the component checks in its README, and add meaningful regression tests. Remote transport changes need real-agent acceptance. Never include secrets or deployment data. Contributions are accepted under the repository’s MIT license; preserve third-party licenses. Be respectful and report security issues privately.

**Türkçe:** Her bileşeni kendi deposunda tutun. Büyük değişiklikleri issue’da konuşun; amacı, davranışı, testleri ve migration/geri dönüş bilgisi belli olan odaklı PR gönderin. Türkçe/İngilizce belge ve arayüzü birlikte güncelleyin. Mevcut biçimi koruyun, README’deki kontrolleri çalıştırın ve anlamlı regresyon testi ekleyin. Taşıma protokolü değişiklikleri gerçek agent testi ister. Sır veya özel kurulum verisi eklemeyin. Katkılar MIT lisansı altında alınır; üçüncü taraf lisanslarını koruyun. Saygılı iletişim kurun, güvenlik açıklarını özel bildirin.
